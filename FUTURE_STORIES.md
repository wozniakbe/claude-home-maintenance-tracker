# Future User Stories

Ideas for future features, roughly grouped by theme.

---

## Search & Discovery

### Search Components and Tasks
> As a user, I can search across all components and tasks by keyword.

### Filter Dashboard Tasks
> As a user, I can filter dashboard tasks by component, status, or date range.

### Calendar View
> As a user, I can view my upcoming tasks in a calendar format.

---

## Task Enhancements

### Task Priority Levels
> As a user, I can set priority (low/medium/high) on tasks to focus on what matters most.

### Postpone/Snooze Tasks
> As a user, I can snooze a task to push its due date forward by a set amount.

### Task Notes/Comments
> As a user, I can add timestamped notes to a task as I work on it over time.

### Bulk Task Operations
> As a user, I can select multiple tasks and complete/skip/delete them at once.

### Task Templates
> As a user, I can create task templates for common maintenance and quickly add them to components.

---

## Component Enhancements

### Component Details/Specs
> As a user, I can record specifications for a component (model number, serial number, purchase date, warranty expiration).

### Component Lifespan Tracking
> As a user, I can set an expected lifespan for a component and see how old it is.

### Document Attachments
> As a user, I can attach documents (manuals, receipts, warranties) to components.

---

## Cost & Vendor Tracking

### Track Maintenance Costs
> As a user, I can log the cost of completing a task to track spending over time.

### Vendor/Contractor Directory
> As a user, I can save contact info for vendors and contractors and associate them with components or tasks.

---

## Notifications & Reminders

### Email Reminders
> As a user, I can receive email reminders for upcoming and overdue tasks.

### Push Notifications (PWA)
> As a user, I can receive browser push notifications for task reminders.

### Digest Emails
> As a user, I can receive a weekly digest of upcoming maintenance.

---

## Multi-User & Sharing

### Invite Family Members
> As a user, I can invite others to view and manage my home's maintenance.

### Activity Log
> As a user, I can see a log of who completed what tasks and when.

---

## Multi-Property Support

### Multiple Homes
> As a user, I can manage multiple properties (home, rental, vacation house) in one account.

### Switch Between Properties
> As a user, I can easily switch context between my different properties.

---

## Seasonal & Smart Features

### Seasonal Maintenance Reminders
> As a user, I get suggested maintenance tasks based on the season (winterize pipes, clean gutters in fall, etc.).

### Smart Home Integration
> As a user, I can connect smart home devices to auto-log certain maintenance (filter replacement detected, etc.).

---

## Data Management

### Export Data
> As a user, I can export all my data (components, tasks, images) for backup or migration.

### Import Data
> As a user, I can import data from a backup or another system.

---

## Mobile Experience

### Progressive Web App (PWA)
> As a user, I can install the app on my phone and use it offline for viewing tasks.

### Mobile-Optimized Image Capture
> As a user, I can quickly take and upload photos directly from my phone's camera.

---

## Quick Wins

### Dark/Light Theme Toggle
> As a user, I can manually switch between dark and light mode.

### Keyboard Shortcuts
> As a user, I can use keyboard shortcuts for common actions (n for new task, etc.).

### Empty State Suggestions
> As a user, I see helpful suggestions when I have no components (common starter components to add).
